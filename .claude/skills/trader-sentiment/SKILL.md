以下の手順で東証翌営業日の市場センチメントを分析してください。

## ステップ1: センチメント分析の実行

$ARGUMENTS が渡された場合はそれを引数として使用し、なければ引数なしで実行します。

```bash
python scripts/run_sentiment.py $ARGUMENTS
```

## ステップ2: 結果の解釈と提示

実行結果を以下の観点で日本語で解釈してください。

### 表示すべき内容

1. **センチメントスコアの解釈**
   - +0.5以上: 強気。積極的な取引を検討。
   - +0.2〜+0.5: やや強気。通常通り推薦銘柄を活用。
   - -0.2〜+0.2: 中立。★3以上の銘柄に絞るのが無難。
   - -0.2〜-0.5: やや弱気。★3以上かつ必要資金の小さい銘柄を優先。
   - -0.5以下: 強気弱気。高リスク。★4〜5のみ、もしくは様子見を推奨。

2. **主要リスク要因の箇条書き**（ニュース内容から読み取れる範囲で）

3. **除外推奨銘柄（risk_tickers）の理由説明**
   - 除外銘柄がある場合、なぜその銘柄がリスクなのかを説明する

4. **取引アドバイス**
   - 今日の推薦銘柄（results/ 以下に最新ファイルがある場合）と照合して
     ★レーティングと合わせた具体的なアドバイスを1〜2文で述べる

### 注意事項

- 本分析はAIによる参考情報であり、投資判断の最終責任はトレーダー本人が負います
- 確信度（confidence）が0.5未満の場合は「不確実性が高い」と明記する
