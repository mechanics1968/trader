以下の手順で翌営業日の推薦銘柄を取得・提示してください。

## ステップ1: 推薦データの取得

### キャッシュ確認

まず `results/` 以下に本日分（today の日付）の推薦ファイルが存在するか確認します。

```bash
ls results/ | sort | tail -5
```

本日分の `recommendations.md` が存在し、`$ARGUMENTS` に `--refresh` や `--retrain` が
含まれていない場合は **ステップ1b（ファイル読み込み）** へ。
存在しない場合や `--refresh` / `--retrain` が指定された場合は **ステップ1a（再実行）** へ。

### ステップ1a: 推薦を新たに生成する

```bash
python main.py $ARGUMENTS
```

### ステップ1b: キャッシュから読み込む

```bash
python scripts/show_recommend.py
```

## ステップ2: 結果の解釈と提示

取得した推薦銘柄を以下の観点で日本語で解釈してください。

### 表示すべき内容

1. **概況サマリー**（1〜2文）
   - 何銘柄が推薦されたか
   - ★レーティングの分布（★4〜5が多い → 強気相場、★1〜2が多い → 慎重相場）

2. **注目銘柄ピックアップ**
   - ★4以上の銘柄を優先的に紹介
   - コード・銘柄名・期待上昇率・必要資金・市場超過確率を簡潔に
   - 元手200万円・1銘柄上限40万円の制約を踏まえたポートフォリオ案（何銘柄まで同時保有できるか）

3. **フィルタ結果**（引数指定がある場合）
   - `--min-rating <N>`: ★N以上の銘柄のみ表示
   - `--max-amount <円>`: 必要資金が指定額以下の銘柄のみ表示

4. **取引アドバイス**（1〜2文）
   - センチメント分析結果がある場合（`/trader-sentiment` を直前に実行済みなど）は
     それと照合して★レーティングの活用方法を述べる
   - なければ★レーティングだけを基にアドバイスする

### ★レーティングの意味

| レーティング | 意味 | 推奨アクション |
|------------|------|--------------|
| ★★★★★ | 市場強気 × 個別スコア最上位 | 積極的に検討 |
| ★★★★ | 市場強気 × 個別スコア上位 | 通常通り検討 |
| ★★★ | 中立 | 慎重に検討 |
| ★★ | 市場弱気 or 個別スコア低位 | リスク認識した上で検討 |
| ★ | 市場弱気 × 個別スコア下位 | 見送りを推奨 |

### 注意事項

- 本推薦はAIによる参考情報であり、投資判断の最終責任はトレーダー本人が負います
- 市場超過確率（close_up_prob）が 0.55 未満の銘柄は特に慎重に
