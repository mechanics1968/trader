以下の手順でモデルの精度・運用状況を確認し、日本語で解釈してください。

## ステップ1: ログファイルの特定

```bash
ls results/ | sort | tail -10
```

本日分（today の日付）を基準に以下のログを探す。

| ファイルパターン | 内容 |
|---------------|------|
| `results/YYYY-MM-DD_backtest.log` | バックテスト結果（`--backtest` 実行時） |
| `results/YYYY-MM-DD_walkforward.log` | ウォークフォワード結果 |
| `results/YYYY-MM-DD.log` | 通常実行ログ（バックテスト結果が埋め込まれていることもある） |

## ステップ2: バックテスト結果の取得

`$ARGUMENTS` に `--backtest` が含まれる、またはキャッシュがない場合:

```bash
python main.py --backtest
```

キャッシュがある場合は直接ログを読む:

```bash
grep -E "(バックテスト結果|方向的中率|AUC|Sharpe|ドローダウン|収益率|RMSE)" results/YYYY-MM-DD_backtest.log | tail -20
```

## ステップ3: ウォークフォワード結果の取得

`$ARGUMENTS` に `--walkforward` が含まれる、またはキャッシュがある場合:

```bash
grep -E "^(平均|推薦|Sharpe|ドロー)" results/YYYY-MM-DD_walkforward.log
tail -10 results/YYYY-MM-DD_walkforward.log
```

## ステップ4: 結果の解釈と提示

### 表示すべき内容

1. **精度サマリー**
   - 終値方向的中率（目標: 55%以上、実用下限: 52%）
   - 推薦銘柄勝率（推薦上位20銘柄が実際に上昇した割合）
   - 日中αAUC（0.5=ランダム、0.55以上が実用ライン）
   - 平均期待収益率・Sharpe Ratio

2. **運用継続の判断基準**

   | 指標 | 判断 |
   |------|------|
   | 方向的中率 ≥ 55% | 良好。このまま運用継続 |
   | 方向的中率 52〜55% | 許容範囲。週1ペースでモニタリング |
   | 方向的中率 < 52% | 要注意。再学習を検討（`/trader-retrain`） |
   | AUC ≥ 0.55 | 良好 |
   | AUC < 0.52 | 再学習を推奨 |

3. **ウォークフォワード傾向分析**（データある場合）
   - 直近5〜10日の推薦勝率トレンド（改善中 / 悪化中 / 横ばい）
   - 推薦ゼロ日が発生していないか確認

4. **総合判断と推奨アクション**（1〜2文）
   - 「運用継続」「要監視」「再学習推奨」のいずれかを明示
   - 具体的な次のアクションを提示

### 注意事項

- 方向的中率はランダムベースラインが50%であることを念頭に解釈する
- 短期（1〜2日）の悪化はノイズの可能性が高い。10日以上の連続悪化で対処を検討
- 本分析はAIによる参考情報であり、最終判断はトレーダー本人が行う
